🟡 UI/UX IMPROVEMENTS / LESS PRIORITY
🟢 SUGGESTIONS / RECOMMENDATIONS
⭐️ WHAT’S WORKING WELL

❣️ Front Page (Sign-In Page)
The partition on the opening page, specifically the sign-in page, is uneven. Suggestion: Give both sides equal space for better balance. 🟡
The logo is too small. It should be made slightly bigger to improve visibility, especially since the background color is almost the same as the surroundings or borders of the logo. 🟡
The tagline is bigger than the name itself. The name of the app or system should be highlighted, especially on the front page. 🟢
The words on the front page, particularly those on the blue background, have too much space on the right side and seem too compressed toward the left. Suggestion: Place the sentences more toward the center for better visual balance. 🟡

❣️ Overview Page
The tabs on the left side are too small, specifically the black background and the font sizes. They are barely noticeable. 🟡
There is too much unused space on the right side after the tables. 🟡
For the tabs showing Sessions Today, Revenue Collected, Slots Available, and Open Incidents, it would be better to place the numbers on the right side or in the middle and make the font slightly larger than the labels. 🟢
Suggestion: Instead of displaying “0% full” for occupancy, it would be better to use something like “100% available” or something similar. This gives a more positive impression to the admin. 🟢
In the Needs Attention section, the words are too close to the flag icon. The same issue can be seen with the occupancy icon. Adjust the text slightly to the right to give the elements better spacing. 🟡
❣️ Pending Registrations Tab/Page
It would be better to place the search bar on the top-right side or top-center rather than on the left side, where the navigation tabs are located. The search icon should also be positioned on the right side. 🟡
The “Nothing waiting in the current page” message would look better if it were more centered. May space kasi sa right side ng page kaya parang 'di din pantay. 🟢

❣️ Parking Tab/Page
The updates to the graph are good, as the changes can be seen immediately. However, there is an issue with the Overview page. When a parking slot is marked as Out of Service, this status does not reflect on the Overview page where the occupancy is displayed. For example, if Gate 1 has 2 occupied slots and 8 slots that are out of service, the occupancy section only shows the 2 occupied slots while the remaining slots are still shown as available. This could become a problem because the occupancy information would not accurately reflect the actual parking status. 🔴
The color changes on the graph are good. The transition from green to orange to red subtly provides a warning when the parking area is getting close to full. ⭐️
The Add Parking Slot button is working properly. The dropdown for vehicle type is also a good touch. There is also a good warning when the admin does not enter a slot code. However, since the slot code is a required field, the interface should indicate “Required” beforehand instead of only showing a warning after the admin clicks the Add button. 🟡
Since I tried adding a new slot on the web, I noticed that there does not seem to be a Delete Slot option. It might be useful to add one. 🟡
Suggestion for logging parking entries: Since there is scanning at the gate, if the admin selects Gate 1, for example, it would be better if the slot-code dropdown automatically filtered the options. Only the slot codes assigned to Gate 1 should be displayed. 🟢
The buttons for Log Entry, Log Exit, and Add Slot are working properly. ⭐️

❣️ Payments Tab/Page
Align the Manage Rates button with the Status dropdown menu. 🟡
The dropdown menu for status is working properly. ⭐️
The Manage Rates function is working properly for adding or updating parking rates. ⭐️
The Close button for the Parking Rates tab would be better placed on the top-right corner. It would also be better to use an “X” icon instead. 🟢

❣️ Violations Tab/Page
The tabs for Violations and Appeals are not properly aligned. Consider moving them slightly to the left, just below the upper heading. 🟡

❣️ Policy Rules
The buttons for adding rules are working properly. ⭐️
The button for editing existing rules is also working properly. ⭐️
There is no proper indication of whether a certain field is required or optional, such as the Title or Description fields for a policy rule. These should be clearly labeled. 🟡
❣️ Incident & Appeals Tab/Page
The placement of the Status filter is inconsistent. On the previous pages, the filter is located on the left side, while on this page, it is placed on the right side. It would be better to keep the placement consistent across all pages if possible. 🟢

❣️ User Management Tab/Page
The spaces allocated for the Full Name, Email, and other fields are not being fully utilized. There is a lot of unused space within the columns. It would be better if the content occupied more of the allocated space. 🟡
The search bar would be better placed on the top-right side. 🟡

❣️ Notifications Tab/Page
The Broadcast button is working properly. However, the fields do not indicate whether they are required or optional. This should be clearly indicated. 🟡

❣️ Reports Tab/Page
Similar to the Overview page, it would be better to place the numbers on the right side or in the middle and make the font slightly larger than the labels. 🟡
For the displayed different sections, such as Total Users, Slots Occupied, and others, it would be better, if possible, to place them all on a single line. Possible naman siguro since may unused space pa sa right side. 🟢
❣️ Audit Log Tab/Page
The dropdown menu for Action is working properly. ⭐️
Keep the spacing on the right side in mind as well, since the unused space is quite noticeable. 🟡

❣️ Lower Part (Account)
The dark and light mode/theme options are working properly. However, when using dark mode, some of the words are no longer visible, particularly the account name and the system name. 🟡
It might be better to use a dropdown arrow instead of the ellipsis (…) for the account menu. 🟢
Center the pop-up tab containing the theme options and logout button. It would also be better to add a simple account/profile icon beside the email address to emphasize that it is an account section. 🟢
There is no logout confirmation. 🔴
